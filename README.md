# 3D-models

Station Navigator: a parametric CAD reconstruction of the Bharati/Maitri main building, built from six dimensioned drawings.

Open `index.html` in a browser (serve it over HTTP, e.g. `python3 -m http.server`, so `model.json` and `parameters.json` load).

## Contents
- `index.html` - the navigable page (overview, drawings, 3D viewer, renders, parameters, validation)
- `model.json` - mesh data used by the 3D viewer
- `parameters.json` - parameter table with confidence tags
- `ref_*.jpg` - source drawings
- `render_*.png` - multi-view renders
